01
AI + CTI

Why human-only analysis breaks at scale.

CTI teams must uncover patterns across huge, mixed datasets. Humans are essential, but manual-only analysis introduces delay, inconsistency, bias and missed patterns.

Too much dataManual examination becomes inconsistent.
Interpretation biasAmbiguous evidence can be read subjectively.
Hidden patternsSubtle signals are easy to miss.
Slow processingThreats stay active while analysts triage.

Five documented benefits of AI in CTI

01Faster response

Automate correlation and routine analysis so standard response can move from days toward minutes.

02Earlier detection

User and entity behaviour analytics can spot anomalies as behaviour changes.

03Predictive analytics

Historical attacks help models support hunting beyond fixed signatures.

04Bias reduction

Data-driven analysis can reduce subjective interpretation when applied carefully.

05Fewer false positives

AI plus human judgement is stronger than either working alone.

02
THREAT HUNTING MATURITY

Start where the organisation actually is.

The maturity model is cumulative. Level 3 does not replace Level 1; it adds capability, policy, specialist people and automation on top of the foundation.

LEVEL 1Basic hunting
  • Centralised SOC + basic IR
  • Collect internal + open-source data
  • Use existing internal analysts
  • Excel / open-source BI is enough to start
LEVEL 2Structured hunting
  • Level 1 foundation already exists
  • Established IR + frequent feeds
  • Analytics and AI classification
  • Formal threat hunting policy
LEVEL 3Mature + automated
  • Mature CTI program
  • Skilled hunting team
  • Automated collection and modelling
  • Integrated hunting platform

THE THREAT HUNTING PROCESS

Hunt with discipline, not curiosity alone.

The five-step process is designed to work at any maturity level. Every hunt starts with purpose and scope, then selects data and techniques, and closes with reporting and feedback.

1Objectives & purpose

Why are you hunting? Define the business-linked goal and hypothesis.

→
2Scope

Define the system under test: business area, subnet, host, server or application set.

→
3Data selection

Select internal + external data that can test the hypothesis.

→
4Technique

Searching, clustering, classification or stack counting.

→
5Report & feedback

Document findings and test whether data + technique were good enough.

Four foundational techniques

SearchingFind IPs, domains, hashes or other indicators.
ClusteringGroup similar events/flows without labels.
ClassificationAssign events to defined classes.
Stack countingCount occurrences to expose unusual elements.

COUPLING CTI WITH THREAT HUNTING

Hunt what is expensive for the adversary to change.

IOC-only hunting is brittle. Hashes, IPs and domains are cheap to replace. TTP-level hunting is more durable because adversaries rarely change their entire operating method.

LOWER PAIN

IOCs

Hashes · IPs · domains · strings

Useful, but cheap for the adversary to change.
→
HIGHER PAIN

TTPs

Tactics · techniques · procedures

Harder to replace because they are tied to how the adversary operates.
ATT&CKTTP reference

Use documented adversary techniques to build hypotheses and analytics.

DIAMONDRelationships

Connect adversary, capability, infrastructure and victim.

KILL CHAINAttack structure

Understand and anticipate activity across the attack lifecycle.

PYRAMID OF PAINDurability

Move upward from cheap-to-change indicators toward expensive-to-change TTPs.

05
HOW ADVERSARIES LEVERAGE AI

The defender is not the only one learning.

The lecture frames AI as a genuine double-edged sword: defenders gain adaptive analytics while adversaries gain adaptive malware, logic bombs, social engineering and automated vulnerability discovery.

SMART MALWARE

Self-evaluate

Observe which part of malicious code triggered defence and adjust behaviour.

SMART MALWARE

Self-actuate

Change behaviour to confuse controls while preserving minimum malicious function.

IMPERSONATION

Blend in

Learn genuine processes and applications so malicious activity looks normal.

SMART WORM

Find + exploit

Check systems for vulnerabilities and propagate automatically.

LOGIC BOMB

Wait for the moment

Trigger based on time, user count, unpatched software or system location.

ATTACK VECTOR

Automate discovery

Use AI to crawl for weaknesses and initiate full-cycle attacks.
