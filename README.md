# COMP6012 Week 10 — AI Applications in Cyber Threat Analytics

A fresh, Vercel-ready interactive lecture website based on the Week 10 lecture deck.

## Concept
**AI Threat Hunt Training Ground** — a classroom-first experience that combines short visible explanations with eight mini-games:

1. Benefit Blitz
2. Maturity Matcher
3. Build the Hunt
4. Technique Picker
5. IOC or TTP?
6. Defender or Adversary?
7. Stack Placement
8. QRadar Pipeline Builder

A 7-question final challenge is included with immediate feedback and score.

## Lecture coverage
- AI benefits and limitations in CTI
- Threat hunting maturity Levels 1–3
- Five-step hunting process
- Searching, clustering, classification and stack counting
- CTI + hunting, ATT&CK, Diamond Model, Kill Chain, Pyramid of Pain
- TTP Threat Hunting V
- AI-enabled adversaries
- AI positioning across SOC, IR, TIP/SIEM and hunting
- IBM QRadar Advisor reference architecture, capabilities and deployment

## Deploy on Vercel
Static site. No build command and no framework dependencies are required.
